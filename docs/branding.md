# هویت نمایشی و نام‌گذاری

نام نمایشی پیش‌فرض این نسخه `Root Bot` است و از طریق `MIRZA_BRAND_NAME` قابل تغییر است:

```bash
export MIRZA_BRAND_NAME="نام دلخواه شما"
```

مقادیر زبان و متن‌های پنل/ربات هنگام بارگذاری، نام‌های نمایشی `Mirza Bot`، `Mirza` و `میرزا` را با نام انتخاب‌شده جایگزین می‌کنند. نام‌های فنی مانند کلاس‌ها، جدول‌های دیتابیس، مسیرهای legacy، متغیرهای سازگاری و نام repository عمداً حفظ شده‌اند تا قابلیت‌های فعلی نشکنند.

این تغییر branding، مجوز `AGPL-3.0-or-later` و attribution پروژه‌ی اصلی را حذف نمی‌کند. در انتشار نسخه‌ی مشتق‌شده، notice مجوز و متن متناظر source باید حفظ شود.
