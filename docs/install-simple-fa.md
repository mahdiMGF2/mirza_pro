# نصب ساده Root Bot

## قبل از شروع

یک سرور تمیز Ubuntu 22.04 یا 24.04، یک دامنه، و یک ربات ساخته‌شده در BotFather لازم دارید.

## نصب

با SSH به سرور وصل شوید و این دستور را اجرا کنید:

```bash
curl -fsSL https://raw.githubusercontent.com/mahdiMGF2/mirzabot/main/install.sh -o install.sh
bash install.sh
```

در منو گزینه‌ی **Install Root Bot** یا گزینه‌ی نصب را انتخاب کنید و اطلاعات خواسته‌شده را وارد کنید:

- توکن ربات تلگرام
- شناسه عددی مدیر
- دامنه
- اطلاعات دیتابیس

بعد از پایان نصب، در تلگرام به ربات پیام `/start` بدهید.

## تغییر نام نمایشی

نام پیش‌فرض **Root Bot** است. برای نام دلخواه، قبل از اجرای PHP این متغیر را تنظیم کنید:

```bash
export MIRZA_BRAND_NAME="نام ربات شما"
```

در نصب معمولی نیازی به این کار نیست.

## به‌روزرسانی

همان دستور را دوباره اجرا کنید و گزینه‌ی **Update** را انتخاب کنید:

```bash
bash install.sh
```

قبل از به‌روزرسانی، از دیتابیس backup بگیرید. installer نسخه‌ی قبلی اسکریپت خود را برای rollback در `/root/install.sh.bak` نگه می‌دارد.

## نکته‌ی مهم

توکن ربات، رمز دیتابیس و کلید پنل را در اختیار دیگران نگذارید. این پروژه تحت مجوز AGPL-3.0-or-later منتشر می‌شود.
